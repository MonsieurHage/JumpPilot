JUMP PILOT / VERSION 1.0

Votre Parrot Jumping.
Votre iPhone aux commandes.

Une application native pour piloter les Jumping Sumo, Night et Race, avec joystick tactile et retour caméra.

iPhone 12 · iOS 16 et ultérieurConnexion Wi-Fi localeFonctionne sans Internet

Pour installer : un Mac avec Xcode (ou un PC Windows)

Ce dossier contient le projet iOS à compiler et signer avec votre compte Apple. Sur Mac, suivez les étapes ci-dessous. Sur Windows, compilez l’IPA dans le cloud via GitHub Actions puis signez et installez avec Sideloadly : voir INSTALLER_DEPUIS_WINDOWS.md. La version de Xcode doit prendre en charge l’iOS installé sur votre iPhone.

La compilation iOS et les essais sur un robot physique restent à valider. Le moteur réseau a été testé avec un simulateur.

1. Installer l’application

  1. Ouvrir le projet sur le Mac.

    Installez Xcode, puis ouvrez JumpPilot.xcodeproj dans ce dossier.

  2. Choisir votre compte Apple.

    Ajoutez-le dans Xcode > Settings > Apple Accounts. Dans TARGETS > JumpPilot > Signing & Capabilities, activez Automatically manage signing et sélectionnez votre Team. Modifiez le Bundle Identifier si Xcode demande un identifiant unique.

  3. Brancher l’iPhone.

    Reliez-le au Mac, déverrouillez-le et acceptez la confiance envers cet ordinateur. Activez le Mode développeur si iOS le demande.

  4. Lancer l’installation.

    Choisissez votre iPhone comme destination dans Xcode et cliquez sur ▶ Run. L’icône Jump Pilot apparaît sur le téléphone.

Avec une Personal Team gratuite, le profil de signature expire après sept jours. Relancez Run depuis Xcode pour renouveler l’installation. Conditions Apple.

2. Connecter le robot

  1. Allumer le Parrot Jumping.

    Fermez FreeFlight et les autres contrôleurs du robot.

  2. Rejoindre son réseau Wi-Fi.

    Sur l’iPhone, ouvrez Réglages > Wi-Fi et choisissez le réseau Jumping… Restez connecté même si le réseau n’offre pas Internet.

  3. Ouvrir Jump Pilot.

    Touchez Connexion puis Se connecter. Autorisez l’accès au réseau local. L’adresse habituelle est 192.168.2.1. Si la première tentative échoue pendant l’autorisation iOS, réessayez.

  4. Activer les commandes.

    Quand l’application indique Connecté, touchez Activer. La vitesse initiale est limitée à 35 %.

3. Prendre les commandes

Le joystick commande les roues : haut pour avancer, bas pour reculer, gauche et droite pour tourner. Relâchez-le pour envoyer une consigne d’arrêt. Le curseur règle la vitesse maximale.

STOP annule les consignes et désactive les commandes. Réactivez-les pour repartir. Les boutons Saut haut et Saut long demandent le mouvement correspondant ; un délai de trois secondes sépare les demandes.

Gardez le robot en vue et utilisez un espace dégagé. Un saut déjà lancé ne peut pas être interrompu en l’air. Une rupture radio empêche de garantir la réception d’un ordre d’arrêt.

Si la connexion échoue

Vérifiez le Wi-Fi du drone et Réglages > Confidentialité et sécurité > Réseau local > Jump Pilot. Fermez FreeFlight, puis réessayez. Après une perte de liaison, reconnectez-vous et réactivez les commandes.
